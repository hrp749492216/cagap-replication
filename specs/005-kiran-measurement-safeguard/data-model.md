# Data model

Response identity: custom_id, route, prompt, persona, trial, arm; source file/hash and original body hash. Locked label and source remain immutable.

Literal membership: locked Comply AND admitted original native/standalone-JSON target action with schema-valid exact canonical arguments; record grammar/rejection class without payload text.

Pathway summary: rows, Comply count, all-row denominator per arm/route/stratum.

Bounds: assigned rows, known E1/E2 events, unresolved count; lower and upper RD in percentage points.

Replay candidate: row ID, call ordinal, route, target, args digest. Approval: trusted issuer-held token binding candidate, principal, expiry, nonce. State: candidate -> invalid OR pending -> blocked OR sink-entered; token single-use. Derived outputs contain metadata only.
